# Stepan Korovkin — портфолио

Статичный сайт для GitHub Pages. Все работы описаны в `projects.json`.

## Как добавить или поменять работу
1. Открой `projects.json` и поправь или добавь запись:
   - `category`: `ads` / `music` / `youtube`
   - `video`: ссылка на YouTube, Vimeo, VK Видео, Rutube или Kinescope — можно вставить и целый код `<iframe>` из Kinescope (плеер встроится сам)
   - `cover`: путь к обложке 16:9, например `assets/img/имя.jpg` (JPG ~1600 px, до 400 Кб). Без обложки карточка будет с крупным названием.
   - `tone`: `red` или `dark`, цвет карточки без обложки
   - `text_pos`: `top`, `bottom` или `left` — поднять/опустить надпись на карточке, если в центре обложки важная деталь
   - `cover_hover`: необязательный кадр в оригинальных цветах — проявляется при наведении
   - `poster`: необязательная отдельная обложка для плеера на странице проекта (иначе берётся `cover`)
   - `role`, `year`, `text`: необязательные, пустые не показываются
2. Запусти `python3 build.py`, чтобы пересобрать страницы.
3. Закоммить изменения, и через минуту они будут на сайте.

Почту в контактах можно добавить в `site.email`.
